**پروکسی منیجر (ProxyManager)** یک ابزار دسکتاپ مدرن، سبک و کاملاً **متن‌باز (Open Source)** برای سیستم‌عامل ویندوز است که امکان مدیریت، سوئیچ سریع و پایش لحظه‌ای کانکشن‌های پروکسی سیستم را به شکلی ساده و چشم‌نواز فراهم می‌کند. این پروژه با پایتون، CustomTkinter و APIهای بومی ویندوز توسعه یافته و بدون نیاز به دسترسی ادمین (UAC) یا باز شدن پنجره‌های آزاردهنده CMD اجرا می‌شود.

---

## ✨ ویژگی‌های کلیدی

- **⚡ تغییر آنی و پرسرعت پروکسی**: تغییر مستقیم تنظیمات پروکسی ویندوز از طریق رجیستری بدون هیچ‌گونه تاخیر یا فلش زدن پنجره سیاه CMD.
- **🎨 طراحی مدرن و دارک تم**: رابط کاربری شیشه‌ای (Glassmorphism) تیره با رنگ‌های اِمرالد (زمردی)، تایپوگرافی خوانا و آیکون‌های وکتور با کیفیت بالا.
- **🛡️ همگام‌سازی زنده وضعیت (Real-time Sync)**: هماهنگی دائمی و خودکار نرم‌افزار با وضعیت واقعی پروکسی ویندوز (اگر از جای دیگری پروکسی قطع یا وصل شود، برنامه فوراً متوجه می‌شود).
- **📊 تست پینگ و تاخیر زنده (Latency Ping)**: امکان سنجش تاخیر پاسخ‌دهی سرور پروکسی با یک کلیک قبل یا بعد از اتصال.
- **🔔 اعلان‌های درون‌برنامه‌ای ثابت (Docked Notifications)**: حذف تمام پنجره‌های معلق و سرگردان قدیمی؛ اعلان‌ها به زیبایی در گوشه پایین-راست پنجره قفل شده و با یک کلیک قابل بستن هستند.
- **📂 مدیریت پیشرفته و هوشمند پروفایل‌ها**:
  - افزودن، ویرایش، تست و حذف آسان سرورهای پروکسی.
  - فیلتر و جستجوی سریع بین پروفایل‌ها بر اساس نام، آدرس IP یا پورت.
  - آنالیزر خودکار آدرس: با پیست کردن مستقیم عباراتی مثل `127.0.0.1:8080` فیلدها خودکار جدا می‌شوند.
- **🚀 مدیریت روشن شدن ویندوز (Startup)**:
  - قابلیت اجرای مینیمایز شده در System Tray هنگام بالا آمدن ویندوز.
  - قابلیت ریست کردن خودکار پروکسی ویندوز در هنگام روشن شدن سیستم برای اطمینان از قطع نبودن اینترنت.
- **📌 پشتیبانی کامل از System Tray**: امکان مخفی ماندن در پس‌زمینه تسک‌بار و دسترسی سریع.
- **🛠️ ابزارهای تشخیصی ویندوز**:
  - دکمه **Flush Windows Proxy** برای بازگرداندن آنی اینترنت در مواقع قطعی ناخواسته.
  - باز کردن آنی صفحه تنظیمات پروکسی ویندوز بدون تاخیر و بدون CMD.
- **📦 نصاب سفارشی با Inno Setup**:
  - امکان تعیین و انتخاب مسیر دلخواه نصب (Custom Installation Directory) در هر درایو و پوشه.
  - حذف‌کننده (Uninstaller) امن که تمام تنظیمات را قبل از پاک شدن ریست می‌کند.

## 📥 راهنمای نصب و استفاده

### روش اول: فایل نصبی ویندوز (پیشنهادی)
فایل نصبی `ProxyManager_Setup.exe` را دانلود کنید:
- ویزارد نصب را باز کنید.
- پوشه دلخواه خود را برای نصب انتخاب کنید (مثلاً `D:\ProxyManager` یا مسیر پیش‌فرض).
- بعد از نصب، برنامه بدون نیاز به مجوز ادمین بلافاصله و با سرعت اجرا خواهد شد.

### روش دوم: فایل پرتابل (Standalone Exe)
فایل اجرایی `ProxyManager.exe` را مستقیماً دانلود و بدون نیاز به نصب اجرا کنید.

## 🛠️ اجرای سورس‌کد با پایتون

### پیش‌نیازها
- پایتون نسخه 3.10 به بالا
- ویندوز 10 یا ویندوز 11

### مراحل اجرا

1. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/ali-aho/ProxyManager.git
   cd ProxyManager
   ```

2. **نصب وابستگی‌ها:**
   ```bash
   pip install -r requirements.txt
   ```

3. **اجرای برنامه:**
   ```bash
   python src/main.py
   ```

## 🔨 بیلد و کامپایل شخصی

### 1. ساخت فایل اجرایی (PyInstaller)
```bash
pyinstaller build_exe.spec --noconfirm
```
فایل اجرایی خروجی در پوشه `dist/ProxyManager.exe` تولید می‌شود.

### 2. کامپایل فایل نصبی (Inno Setup)
در صورتی که Inno Setup 6 روی سیستم نصب باشد:
```bash
iscc setup.iss
```
فایل نهایی نصبی در مسیر `dist/ProxyManager_Setup.exe` قرار خواهد گرفت.
